### 1. 下拉快捷面板布局重做

根据实物反馈将快捷面板从"竖条亮度+按钮"改为现代手机风格：

- 面板尺寸 240×150 → **240×160**（加高 10px，亮度条与按钮拉开间距）
- 四个快捷按钮（WIFI / BLE / OFF / PWR）2×2 网格排列
- 按钮内图标与文字改为**水平居中**（`LV_ALIGN_TOP_MID`），解决图标贴左问题
- 亮度条改为面板底部**通栏横条**，比原来右下角 48×56 小竖条空间大得多
- 亮度百分比移到滑块**左侧**，滑块右移避开文字（20% 初始填充不会盖住百分比）
- 太阳图标 18 → **24 号字体**放大，用 `LV_ALIGN_OUT_RIGHT_MID` 与滑块**垂直居中对齐**（再上移 3px 补偿星号字符视觉偏下）

最终亮度行布局：

```text

  左端        中间         右端
```

三者垂直中心在同一水平线上，滑块 100% 时填充只在轨道内部，永不遮挡百分比。

### 2. 触摸交互修复：点面板不再误关

之前 `ui_handle_touch()` 在按下瞬间无条件收起面板，导致面板里的按钮和滑块永远无法响应（点哪都是收起）。修复：

- 新增 `ui_quick_panel_hit(x, y)` 判断触摸点是否在面板区域内
- **面板内**点击 → 交给 LVGL 正常分发，按钮/滑块可操作
- **面板外**点击 → 收起面板
- 上滑手势、息屏（OFF 键）、亮屏恢复统一走 `ui_quick_panel_close()` 收口
- 面板收起终点同步改为 -160（配合面板加高）

### 3. 启用 24 号字体

# 2026-08-25 晚间补充：ESP32-C3 / AHT21 接入准备

## 一、最终硬件方案

由于扩展板与核心板对插后，只有 H1（底部 2×9）和 H2（左下角 1×4）可以接线，放弃直接使用 USART1 的 PA9/PA10 接口，采用 USART6 方案。

### USART6 / ESP32-C3

```text
STM32 PC6  = USART6_TX
STM32 PC7  = USART6_RX
USART6     = 115200 8N1，无校验，无硬件流控
```

### AHT21

```text
STM32 PC4 = 软件 I2C SCL
STM32 PC5 = 软件 I2C SDA
AHT21 地址 = 0x38
```

CST816 触摸屏继续使用原来的 PB6/PB7 软件 I2C，不与 AHT21 共线。

## 二、明日实际接线表

### ESP32-C3 与 STM32

```text
H2 Pin3 / PC6 / STM32 TX -> ESP32-C3 GPIO20 / UART1_RX
H2 Pin4 / PC7 / STM32 RX <- ESP32-C3 GPIO21 / UART1_TX
H2 Pin2 / GND             -> ESP32-C3 GND
```

TX 和 RX 必须交叉连接。ESP32-C3 开发期间使用自身 Type-C 供电，STM32 使用核心板 USB2 供电。

### AHT21 与 STM32

```text
H1 Pin1  / 3V3 -> AHT21 VCC
H1 Pin2  / GND -> AHT21 GND
H1 Pin10 / PC4 -> AHT21 SCL
H1 Pin9  / PC5 -> AHT21 SDA
```

AHT21 的 SDA/SCL 需要上拉到 3.3V；如果模块自带上拉，必须确认不是上拉到 5V。

PB15/PB2 当前不用于串口，避免与早期连接指南中的旧方案混淆。

- CRC8 校验
- 温度和湿度整数定点值解析

### 4. 传感器任务

新增：

```text
User/Tasks/Inc/user_SensorTask.h
User/Tasks/Src/user_SensorTask.c
```

任务每 2 秒采集一次温湿度，保存数据快照；LVGL 任务在自身上下文中读取快照并更新主页环境卡，避免传感器任务直接操作 LVGL。

## 四、界面相关改动

- 删除主页没有对应硬件的步数卡。

- 设置页增加可调自动息屏时间，范围 0~60 秒，默认 30 秒。

- 触摸或 PA0 按键会刷新活动时间，超时关闭背光，触摸/按键可唤醒。

1. 焊接 H1/H2 排母。
